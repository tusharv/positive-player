Use the wordmark without stretching. Leave at least the height of the lowercase “in” around it. The small icon uses the year without the domain suffix for legibility.

Colours: broadcast blue `#183b9b`, paper `#f5f4ed`, ink `#182645`, secondary text `#586078`, pale blue `#e6eafa`. The tiny test-pattern accent uses gold, cyan, green, mauve, coral, and blue. Main English copy uses Arial/Helvetica; Hindi uses the existing self-hosted Tiro Devanagari Hindi; channel numbers use IBM Plex Mono.

The home page is `/`; the television is `/watch`. The programme lineup is unchanged. The name refers to the inspiration for the viewing experience, not a strict programme year or an official broadcaster affiliation.
